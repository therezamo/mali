# هل اول

سامانهٔ مدیریت مالی شخصی و بودجه‌بندی. برنامه به‌صورت یک صفحهٔ ایستا اجرا می‌شود و به سرور یا ساخت فرانت‌اند نیاز ندارد.

## انتشار

در تنظیمات مخزن GitHub Pages را روی شاخهٔ `main` و پوشهٔ ریشه (`/`) بگذارید. فایل `index.html` صفحهٔ اصلی است.

## ذخیرهٔ اطلاعات

پروفایل، بودجه‌ها، تراکنش‌ها و چک‌لیست در `localStorage` همان مرورگر ذخیره می‌شوند. برنامه حساب کاربری یا همگام‌سازی بین دستگاه‌ها ندارد. برای جابه‌جایی اطلاعات از دکمه‌های پشتیبان‌گیری و بازگردانی JSON استفاده کنید.

فونت و کتابخانه‌های رابط کاربری داخل همین مخزن میزبانی می‌شوند و برنامه برای اجرا به CDN نیاز ندارد. برنامه اطلاعات را به سرور نمی‌فرستد؛ داده‌ها فقط در مرورگر ذخیره می‌شوند. کلید اختصاصی این برنامه `hal_e_avval_financial_suite_v2` است تا با کلید برنامه‌های دیگر تصادم نکند. صفحه‌های `therezamo.github.io` از فضای ذخیره‌سازی مرورگر مشترک استفاده می‌کنند؛ این کلید جدا جلوی قاطی‌شدن معمول داده‌ها را می‌گیرد، اما مرز امنیتی بین برنامه‌های هم‌دامنه نیست. GitHub Pages صفحه را عمومی می‌کند و خود برنامه حساب کاربری یا رمزنگاری داده‌ها ندارد؛ اطلاعات حساس را روی دستگاه مشترک وارد نکنید.

برای بازسازی فایل CSS پس از تغییر ظاهر برنامه، وابستگی‌ها را با `pnpm install` نصب و `pnpm build:css` را اجرا کنید. فایل CSS خروجی در `assets/css/app.css` قرار می‌گیرد.
